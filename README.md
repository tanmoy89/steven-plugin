# Steven för Claude

Claude-tillägg för Steven, Greenelys marknadsassistent. Tillägget innehåller bara adressen till Steven-servern och en kort instruktion. All kunskap och alla verktyg ligger på servern bakom inloggning med ett @greenely.se-konto, och åtkomst kräver inbjudan.

Installera:

```
claude plugin marketplace add tanmoy89/steven-plugin
claude plugin install steven@greenely
claude mcp login plugin:steven:steven
```
